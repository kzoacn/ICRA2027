# Archive

This directory preserves earlier development and deployment evidence.
For current commands, use the [setup guide](../docs/setup.md).

| Directory | Contents |
| --- | --- |
| [evaluated-source/](evaluated-source/) | Exact frozen source of the current 94.0% full evaluation |
| [experiments/](experiments/) | Earlier development records and archived episode datasets |
| [deployment/](deployment/) | Original deployment instructions, checksums and provenance |
| [jobs/](jobs/) | Historical server dispatchers and configurations |

Historical scripts and records retain original method identifiers and host paths.
They document their original runs and may need adaptation before execution on a
new machine. See [repository conventions](../docs/repository.md) for the current
names and the evaluated source mapping.

The original 360/400 full evaluation is retained in
[full400-reference/](experiments/full400-reference/), and the later 374/400
combined task-retest records are in
[task-updates-reference/](experiments/task-updates-reference/).
Their raw records and provenance retain their original checksums. References to
removed publication files inside frozen JSON records describe the historical
state and are not current file locations.
